# 真机验证清单

本项目在 Linux 云端 + GitHub Actions macOS Runner 上开发。云端只能做到：

- Linux / macOS 上 `swift test`（纯逻辑、状态机、编解码、模拟器件）；
- Xcode 编译 iOS / watchOS（模拟器与不签名的真机架构）；
- iOS 模拟器上的单元测试与 UI 测试（**仅使用演示模式的模拟数据**）。

下列事项**必须在真机上验证**，云端的编译成功或模拟测试通过都不代表这些项通过。每项验证后请在“结果”列填写日期、设备与系统版本。

## 已知风险（需真机确认）

1. `HKLiveWorkoutBuilder` 在 `session.end()` 之后再 `endCollection` / `finishWorkout` 的顺序：采用 watchOS 早期文档写法，若真机出现保存失败，改为在 `.stopped` 状态回调中结束采集。
2. iPhone 被系统后台拉起投递镜像会话：已在 `application(_:didFinishLaunchingWithOptions:)` 中注册处理器，但未验证在 App 被杀后的行为（3.5）。
3. 断线判断依赖 `didDisconnectFromRemoteDeviceWithError` 与发送失败回调；真实蓝牙抖动下的触发频率未知，可能需要调整 12 秒“信号弱”阈值与重连退避参数。
4. HealthKit 回调的 Swift 6 并发处理（`nonisolated` 包装 + 主队列转交）只经过编译验证。
