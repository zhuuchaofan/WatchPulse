# 真机验证清单

本项目在 Linux 云端 + GitHub Actions macOS Runner 上开发。云端只能做到：

- Linux / macOS 上 `swift test`（纯逻辑、状态机、编解码、模拟器件）；
- Xcode 编译 iOS / watchOS（模拟器与不签名的真机架构）；
- iOS 模拟器上的单元测试与 UI 测试（**仅使用演示模式的模拟数据**）。

下列事项**必须在真机上验证**，云端的编译成功或模拟测试通过都不代表这些项通过。每项验证后请在“结果”列填写日期、设备与系统版本。

图例：⬜ 未验证 · ✅ 通过 · ❌ 失败
